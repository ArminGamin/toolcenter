# ToolsAI Control Center

Production local launcher for tools in `D:\toolsai`.

## Run

```powershell
cd D:\toolsai\control-center
npm install
npm run dev
```

Open **http://127.0.0.1:5173** — top bar should say **Bridge on**.

- Click a tool → **Launch**
- **Open folder** opens Explorer
- Double-click an orbit node to launch instantly
- Press `/` to jump/search

## Tools synced to disk

Scraper · DC Scraper · Newsletter Sender · PostMaker · AI Lead Finder · Gmail Script · Motion Blur · Video Creator

## Build

```powershell
npm run build
npm run preview
```
